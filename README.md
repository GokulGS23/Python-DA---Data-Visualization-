# Python-DA---Data-Visualization-


Description

This assignment focuses on learning and practicing data visualization using Python. It includes loading and exploring a dataset, handling missing values, and creating different types of visualizations using Matplotlib, Pandas, and Seaborn.

The assignment uses the Seaborn Taxis dataset to analyze taxi trip information such as pickup locations, fares, distances, tips, payment methods, and other trip-related data.

---

Topics Covered

Data Loading and Exploration

Data Cleaning

Matplotlib and Pandas Visualizations

Seaborn Visualizations



---

Dataset Used

Taxis Dataset

The assignment uses the Taxis dataset available through the Seaborn library.

The dataset contains information related to taxi trips, including:

- Pickup Date and Time
- Drop-off Date and Time
- Pickup Location
- Drop-off Location
- Pickup Borough
- Drop-off Borough
- Distance
- Fare
- Tip Amount
- Toll Amount
- Total Amount
- Payment Method
- Color
